ACNA BCP 2019 Daily Office Calendar

A subscribe-able calendar feed for the Anglican Church in North America's Book of Common Prayer 2019.

Each day includes the liturgical day name plus Morning Prayer and Evening Prayer readings.

Coverage: 2026-01-01 through 2028-12-31

Add to Google Calendar Open ICS Feed

What This Calendar Is

One all-day event for every date in the generated range. Each event contains:

  • Liturgical day name
  • Morning Prayer Psalms, OT, NT
  • Evening Prayer Psalms, OT, NT

This is a read-only reference calendar designed for prayer planning and quick daily lookup.

How To Subscribe

Google Calendar: use the button above.

Apple Calendar / Outlook: subscribe by URL using:

https://church-calendar.pages.dev/acna-bcp2019.ics

Subscription means updates are delivered automatically when this site is rebuilt.

How To Use It

  • Open today in your calendar app.
  • Read the event description for Daily Office references.
  • Tap the event URL to view a clean day page in browser.

Example day page:

https://church-calendar.pages.dev/day/2026-01-01/

About ACNA & the BCP 2019

The readings and liturgical names are generated to support use of the ACNA Book of Common Prayer 2019 Daily Office tradition.
